# Avinash Kumar Sharma | Personal Portfolio

A responsive personal portfolio website designed to showcase my journey as a BTech CSE student and aspiring Java Full Stack Developer. This repository contains the source code for my web portfolio, highlighting my technical skills, software engineering projects, and professional background.

## ✨ Key Features

* **Interactive Project Gallery:** A clean, dynamic showcase of my recent full-stack work, including projects like PGLife and my Student Management System.
* **Responsive Navigation Sidebar:** Ensures smooth user experience and easy access across all screen sizes (mobile, tablet, and desktop).
* **One-Click Resume Download:** A streamlined PDF download section for recruiters and collaborators to easily access my CV.
* **Contact Integration:** A backend-connected contact form for direct inquiries.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Design/UI:** Responsive Web Design, Custom Vector/SVG Assets
* **Backend Integration:** PHP/Contact Processing (Adjust if using a different form handler)
